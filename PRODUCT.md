# Product context (impeccable)
- Product: demo website for a fictional landscaping company (Alder & Stone Landscape Co.), built by SVK (mavrickweb.com) as a reusable template / portfolio piece.
- Audience: homeowners in a small-town / suburban service area, mostly on phones.
- Surface mode: Persuade. Success = phone call or quote request.
- Platform: web (static Astro + Tailwind v4), light mode only (daylight, outdoor phone use).
- Constraints: sample data clearly labeled; no testimonials/reviews; openly licensed images with credits; noindex while demoMode is on.
- Voice: plain, specific, competent. Talks about plants, soil, seasons and schedules, not "elevating outdoor experiences".
